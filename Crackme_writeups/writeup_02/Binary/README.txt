My First Crackme

Goal: Find the correct serial to pass the check.

How to run:
1. Install .NET 9.0 Runtime (https://dotnet.microsoft.com/en-us/download/dotnet/9.0)
2. Open terminal/cmd in this folder.
3. Run: dotnet chip-8.dll
4. Examine the code for serial
5. Enter serial when asked.

If you see "Correct!" you solved it!
